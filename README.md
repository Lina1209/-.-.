# Руны Ведьм & Исландские руны

Декоративные рунические шрифты от **Lina Winter**.

Набор включает два шрифта:
- **Руны Ведьм**
- **Исландские руны**

Каждый шрифт доступен в двух версиях: **чёрной** и **белой**.

## О рунах

**Руны Ведьм** — современный магический алфавит, созданный в XX веке для ведьмовской практики. Используются в заклинаниях, амулетах, медитациях и работе с энергией. Каждая руна несёт конкретное намерение: защита, любовь, сила, очищение, удача и другие.

**Исландские руны** (исландские гальдраставы и рунические ряды) — традиционные символы северной магии. Применяются для защиты, привлечения удачи, усиления воли и создания магических знаков. Многие из них сохранились в исландских гримуарах и до сих пор используются в современной эзотерике.

## Версии шрифтов

| Шрифт              | Версия     | Описание                          |
|--------------------|------------|-----------------------------------|
| Руны Ведьм         | Чёрная     | Основная тёмная версия            |
| Руны Ведьм         | Белая      | Для использования на тёмном фоне  |
| Исландские руны    | Чёрная     | Основная тёмная версия            |

## Установка

### Windows
1. Скачайте нужные файлы шрифта
2. Щёлкните правой кнопкой мыши по файлу → **Установить**

### macOS
1. Дважды щёлкните по файлу шрифта
2. Нажмите **Установить шрифт**

### Linux
```bash
mkdir -p ~/.local/share/fonts
cp *.ttf ~/.local/share/fonts/
fc-cache -fv
```

## Использование

После установки шрифты появятся в списке доступных шрифтов в программах (Adobe Photoshop, Illustrator, Figma, Canva, Microsoft Word и др.).

**Рекомендации:**
- Для светлого фона используйте **чёрную** версию
- Для тёмного фона — **белую** версию
- Шрифты лучше всего раскрываются на крупных кеглях (от 24 px и выше)
